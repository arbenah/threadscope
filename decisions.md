##1 Why is this being done?

I choose to use a simple HTML, CSS, and JavaScript implementation instead of a more extensive frontend framework. Since the landing page does not presently need routing, complex state management, or application-level component design, a framework would raise setup and dependency overhead without providing much user value.

The interface itself conveys the product concept rather than making unsupported marketing promises. I deliberately avoided client logos, use data, and phony testimonials. Rather than merely stating that the product is useful, the hero immediately shows the visitor a genuine ThreadScope workstation.

##2 Trade-off in terms of time

For me, the core landing-page experience, responsive behavior, and product engagement were more crucial than implementing a real backend or AI workflow.

The "Generate direction" interface is therefore a frontend prototype rather than a production AI function.

I would develop a genuine recommendation pipeline, add permanent projects and authentication, integrate true reference uploads, and link the frontend to a backend in a whole week. I would also do out more extensive performance, accessibility, and cross-browser testing.

I removed unnecessary conversations, removed unsupported claims, and made the final decisions on hierarchy, space, font, and motion.

The final solution is intentionally simple so that I can teach HTML, CSS, and JavaScript in the follow-up discussion.
 
 ##3 AI instruments

I reviewed implementation strategies, investigated copy variants, identified possible responsive-design concerns, and brainstormed product concepts using AI technologies.

Instead of considering the produced result to be authoritative, I personally inspected and changed it. I created the final choices regarding hierarchy, space, typeface, and motion after testing the layout at desktop and mobile sizes, streamlining pointless interactions, and eliminating unsubstantiated claims.

In order for me to teach HTML, CSS, and JavaScript during the follow-up conversation, the final implementation is purposefully modest.
